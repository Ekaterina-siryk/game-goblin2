# Игра "Whack-a-Goblin" (Yarn & OOP)

![CI](https://github.com/Ekaterina-siryk/game-goblin2/actions/workflows/deploy.yml/badge.svg)

Вы решили доделать игру с гоблинами, поэтому нужно реализовать остальную логику.

Я
Нужно доделать игру с гоблинами, реализовав такую ​​логику:

Появление гоблина в случайном месте (набор точек фиксирован) ровно на 1 секунду
Если пользователь успел за это время кликнуть по этому месту (попробуйте сделать пользовательский курсор в видео молотка), то:
пациент засчитывается +1 балл
гоблин выпадает из камеры
Если пользователь пропустил 5 появлений гоблинов, игра завершится.
Попробуйте реализовать всё не в виде простого скрипта, разбивающего приложение по классам, каждый из которых ответственен за определённую логику.

Всё должно собираться через Webpack (включая картинки и стили) и выкладываться на Github Pages через CI.

В результате пришлите ссылку на ваш GitHub-проект. Не забудьте установить бейджик сборки.

## Команды проекта (Yarn)
* `yarn install` — установка зависимостей (генерирует `yarn.lock`).
* `yarn start` — запуск локального веб-сервера.
* `yarn test` — прогон тестов.
* `yarn run lint` — линтинг проекта.
* `yarn run build` — продакшн-сборка.
